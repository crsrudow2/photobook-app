# Photobook App — Agent Context

## What We're Building
A full-stack Mixbook-style photo book creation platform. Think Mixbook.com: users upload photos, arrange them on canvas templates to create photo books, add to cart, and check out.

## Repo
- GitHub: https://github.com/crsrudow2/photobook-app
- Local: ~/Claude/photobook-app
- Branch strategy: feature branches, PRs to main

## Stack
- **Frontend**: Next.js 14 (App Router), TypeScript, Tailwind CSS
- **Database**: PostgreSQL via Docker Compose + Prisma ORM
- **Auth**: NextAuth.js (credentials + OAuth)
- **Canvas editor**: Fabric.js
- **Payments**: Stubbed locally (no real Stripe account yet) — implement the full UI/UX flow, just mock the payment API calls
- **File storage**: Local filesystem for now (store uploads in /public/uploads or use a local multer setup) — no S3 account yet

## Architecture
```
src/
  app/                  # Next.js App Router pages
    (auth)/             # login, register
    (shop)/             # product listing, PDPs
    editor/             # photo book canvas editor
    cart/               # cart + checkout
    account/            # order history, profile
    admin/              # admin panel
  components/           # shared UI components
  lib/                  # prisma client, auth config, utils
  types/                # TypeScript types
prisma/
  schema.prisma         # database schema
docker-compose.yml      # PostgreSQL
```

## Database Schema (implement in Prisma)
- User (id, email, name, passwordHash, role, createdAt)
- Product (id, name, description, category, basePrice, sizes JSON, coverTypes JSON, pageOptions JSON, images JSON, slug, active)
- Template (id, name, category, thumbnail, fabricJson, pageCount)
- Project (id, userId, productId, templateId, title, fabricJson, status, createdAt, updatedAt)
- CartItem (id, userId, projectId, quantity, price, options JSON)
- Order (id, userId, status, total, shippingAddress JSON, createdAt)
- OrderItem (id, orderId, projectId, quantity, price, options JSON)

## Key Features to Build
1. **Product catalog** — photo books, canvas prints, cards with variants (sizes, cover types)
2. **Canvas editor** — Fabric.js drag-and-drop editor: add photos, text, backgrounds, resize, reorder pages
3. **Photo upload** — drag-drop upload to local storage, shown in editor sidebar
4. **User auth** — email/password registration + login with NextAuth
5. **Cart + checkout** — full cart flow, stubbed payment (always succeeds in dev)
6. **Order management** — order confirmation, history in account page
7. **Admin panel** — manage products, view orders

## Stubs

- **Email**: Log emails to console, don't send real ones
